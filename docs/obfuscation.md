# Деобфускация

## 1. Расшифрованная строка
`import os; os.system('rm -rf /')`

## 2. Анализ угрозы
Выполнение скрипта приведет к критической угрозе. Команда `rm -rf /` запускает рекурсивное (`-r`) и принудительное (`-f`) удаление всех файлов из корневой директории `/`. Это уничтожит операционную систему и все данные на диске.

## 3. Методы защиты
1. Использование статического анализа (SAST) для поиска вызовов `exec` и `eval`.
2. Запуск кода с минимальными правами доступа (принцип наименьших привилегий).
3. Блокировка небезопасных функций динамического выполнения кода.
