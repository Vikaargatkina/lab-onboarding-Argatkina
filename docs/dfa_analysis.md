# Анализ потоков данных (DFA)

## 1. Цепочки Def-Use
* **log_entry**: Def (стр. 2, 10) -> Use (стр. 13)
* **status**: Def (стр. 5) -> Use (стр. 10, 15)
* **balance**: Def (стр. 6) -> Use (стр. 7)
* **new_balance**: Def (стр. 7) -> Use (стр. 8)
* **file**: Def (стр. 12) -> Use (стр. 13)

## 2. Скрытые дефекты
1. **Неинициализированная переменная**: Переменная `status` (стр. 10) не будет создана, если `amount <= 0`. Это вызовет ошибку `UnboundLocalError`.
2. **Мертвое присваивание (Dead Store)**: Строка 2 присваивает `log_entry` значение, которое никогда не читается, так как на строке 10 переменная перезаписывается.
3. **Утечка ресурса (Resource Leak)**: В строке 12 открывается файл (`file = open(...)`), но метод `file.close()` отсутствует.
