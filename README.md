# Автоматизированный аудит программного обеспечения (Практическая 9)

Скрипт предназначен для сбора информации о системе и автоматического интеллектуального аудита установленного программного обеспечения.

## Что было сделано (Рефакторинг):
* **Подпрограмма `:log`:** Весь вывод дублируется одновременно в консоль и в файл отчёта без повторения команд `echo`.
* **Временные метки:** В начало отчёта автоматически добавляется текущая дата и время запуска проверки.
* **Индикаторы прогресса:** В консоль выводятся маркеры этапов выполнения скрипта (`[1/5]`, `[2/5]` и т.д.).

## Аналитический блок (Аудит ПО):
1. **Базовое ПО:** Проверяет наличие архиваторов (7-Zip, WinRAR) и офисных пакетов. Если они не найдены, выдаёт рекомендацию по установке.
2. **Излишнее ПО:** Ищет следы нецелевых программ (игры Steam/Epic, торренты uTorrent, мессенджеры Discord). При обнаружении добавляет их в блок, требующий проверки информационной безопасности.

## Состав папки `client-check`:
* `pc_info.bat` — исполняемый скрипт диагностики.
* `pc_report.txt` — автоматически генерируемый отчёт с результатами проверки.
* `screenshot_audit.png` — скриншот успешного выполнения работы скрипта в консоли.
