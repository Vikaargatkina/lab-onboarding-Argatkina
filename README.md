# Автоматизированный аудит программного обеспечения (Практическая 8, Часть 2)

Скрипт предназначен для сбора информации о системе и автоматического интеллектуального аудита установленного программного обеспечения методом сверки с эталонными списками.

## 1. Выбранные категории базового ПО и обоснование
* **Архиватор (7-Zip, WinRAR):** Необходим для распаковки рабочих материалов, архивов с документами и вложений из электронной почты.
* **Офисный пакет (Office, LibreOffice, МойОфис):** Базовый инструмент сотрудника для создания текстовых документов, таблиц и презентаций.

## 2. Признаки излишнего ПО (Группы риска)
* **Нецелевой софт (Steam, uTorrent, Discord):** Программы, которые не относятся к выполнению базовых офисных задач. Создают угрозу информационной безопасности, нагрузку на локальную сеть и отвлекают сотрудников.

## 3. Проверка работоспособности логики скрипта
Тестирование ветвей логики проводилось методом ручной модификации временного списка ПО:
* **Проверка ветки "Не обнаружено":** Из файла `apps_list.txt` временно удалялись упоминания MS Office и 7-Zip. Скрипт корректно отработал и вывел в отчёт блоки `[РЕКОМЕНДАЦИЯ]` с предложением установить софт.
* **Проверка ветки "Обнаружено излишнее ПО":** Во временный файл принудительно дописывалась строка `Steam`. Скрипт успешно отреагировал, зафиксировав программу и выведя её в раздел `[ТРЕБУЕТ ПРОВЕРКИ]`.

## 4. Ограничения текущего решения
* Скрипт выполняет статический поиск по ключевым словам. Если папка или имя программы в реестре изменены, софт может быть не распознан.
* Поиск завязан на системный реестр Windows (раздел Uninstall). Портативные версии программ (Portable), запускаемые без установки, в анализ не попадают.
* Требуются права на чтение веток реестра (в коде реализован обход потенциальных ошибок через перенаправление потоков `2>nul`).
